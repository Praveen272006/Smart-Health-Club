# Smart Health Club Management

A responsive web app for managing campus health club events, members, attendance, and reports. It provides a shared sign-in screen with separate Student, Board Member, and Admin / Faculty experiences.

## Features

### Student
- View the dashboard and wellness snapshot
- Browse club events and register interest
- View attendance and profile details
- Explore wellness resources

### Board Member
- View club engagement and approval requests
- Scan student IDs and manage attendance
- Review pending approvals
- Browse members and reports
- Manage board member profile

### Admin / Faculty
- View club events and dashboard summaries
- Create and edit events
- Invite members to the directory
- Search and filter members by attendance status
- Export attendance records as CSV

Attendance scanning and approvals are available only to Board Members.

- CSS
